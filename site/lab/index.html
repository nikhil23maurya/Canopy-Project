    Technical notes

    Why is the greedy choice optimal?

    An optimal binary prefix tree can place the two least frequent symbols as deepest siblings. Swapping those two with any deeper leaves cannot increase the weighted path length. Replace their parent with a single combined symbol, solve the smaller problem, then expand the pair.

    How is the archive structured?

    HUF1 stores an 18-byte fixed header, 2 bytes per distinct symbol for its value and code length, and the packed bitstream. Canonical coding preserves the lengths from the merge tree and assigns the codes in length-then-byte order. The tree shown above illustrates the greedy merges. The archive uses the canonical bit patterns.

    What is the running time?

    Counting and encoding take O(n) for a fixed byte alphabet. The min-heap builds the tree in O(k log k), with k ≤ 256. The browser also holds input and output byte buffers in memory during a run.
